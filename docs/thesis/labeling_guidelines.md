# Правила ручной разметки страниц NoteVision OMR

## Назначение

Документ задаёт единые правила заполнения `page_type`, `has_music` и
`quality_comment` для корпуса ВКР. Разметка описывает основное содержимое
страницы и её пригодность для последующего OMR.

Если страница уверенно относится к одному типу, не следует использовать
`unknown`. Пограничные решения нужно кратко объяснять в `quality_comment`.

## Общие правила

- `has_music = 1`, если страница содержит существенную нотную запись.
- `has_music = 0`, если нот нет либо изображение технически непригодно для OMR.
- Небольшой декоративный нотный фрагмент не делает страницу `music`, если
  основное содержание является титульным или текстовым.
- Номер страницы без другого содержания относится к `blank`.
- Для фото-сканов, рукописных нот и дефектов следует добавлять короткий
  стандартизированный комментарий: `photo scan`, `handwritten music`,
  `cropped`, `blurred`, `Kodak Color Control Patch` и т. п.

## `title`

Использовать для:

- титульных страниц;
- обложек;
- издательской информации;
- выходных данных без существенной нотной записи.

Значение: `has_music = 0`.

Примеры текущего корпуса:

- `rsl01001872102/page_001`;
- `rsl01001872102/page_005`;
- `rsl01004466011/page_001`;
- `rsl01004468752/page_001`.

## `text`

Использовать для:

- оглавлений;
- предисловий;
- каталогов;
- текстовых инструкций и примечаний без существенных нот.

Значение: `has_music = 0`.

Примеры текущего корпуса:

- `rsl01001872102/page_007`–`page_011`;
- `rsl01004471003/page_003`;
- `rsl01004472531/page_005`–`page_006`.

## `blank`

Использовать для:

- пустых страниц;
- страниц только с номером (`page-number-only`);
- bleed-through;
- ghosting;
- слабых следов оборотной стороны без самостоятельного содержания.

Значение: `has_music = 0`.

Примеры текущего корпуса:

- `rsl01001872102/page_003`;
- `rsl01001872102/page_004`;
- `rsl01001872102/page_059`–`page_063`;
- `rsl01004466011/page_002`–`page_003`.

## `music`

Использовать для:

- печатных нот;
- рукописных нот;
- партитур;
- инструментальных и вокальных партий;
- страниц, где нотная запись является основным содержанием.

Значение: `has_music = 1`.

Примеры текущего корпуса:

- `rsl01001872102/page_013`–`page_017`;
- внутренние страницы документов, вручную подтверждённые как нотные.

Для рукописной страницы добавить в комментарий `handwritten music`.

## `mixed`

Использовать, если на странице одновременно присутствуют существенный текст и
существенная нотная запись. Небольшая подпись, заголовок произведения или
текст вокальной партии под нотами сами по себе не требуют типа `mixed`.

Значение: `has_music = 1`.

Примеры текущего корпуса:

- `rsl01004473921/page_003`;
- `rsl01004475471/page_003`;
- `rsl01004475471/page_006`–`page_007`;
- `rsl01004475471/page_009`.

## `bad_scan`

Использовать для страниц, технически непригодных для OMR:

- Kodak Color Control Patch вместо документа;
- сильная обрезка нотного текста;
- размытый снимок;
- крупные дефекты экспозиции или геометрии;
- изображение, по которому невозможно надёжно восстановить страницу.

Обычно: `has_music = 0`.

Если ноты видны, но качество только снижено, следует оставить `music` или
`mixed` и описать дефект в `quality_comment`. `bad_scan` применяется, когда
дефект препятствует содержательной OMR-обработке.

На момент подготовки guidelines в текущем `pages_validated_thesis.csv` не было
страниц, окончательно подтверждённых как `bad_scan`. Первый выявленный пример
следует добавить сюда после ручной проверки.

## `unknown`

Использовать только тогда, когда невозможно определить тип страницы без
дополнительной проверки.

Обычно `has_music` остаётся предварительным, а страница должна сохранять
`needs_review = 1`.

Примеры страниц, требующих уточнения в текущем корпусе:

- `rsl01001872102/page_002`;
- `rsl01001872102/page_006`;
- `rsl01001872102/page_064`;
- `rsl01004469140/page_002`;
- `rsl01004470882/page_001`.

## Комментарии качества

Рекомендуемые короткие маркеры:

| Маркер | Значение |
|---|---|
| `photo scan` | Страница сфотографирована, а не получена плоским сканированием |
| `handwritten music` | Рукописная нотная запись |
| `Kodak Color Control Patch` | Техническая цветовая шкала |
| `cropped` | Существенная обрезка |
| `blurred` | Размытие |
| `bleed-through` | Просвечивание оборотной стороны |
| `ghosting` | Слабое дублированное изображение |
| `page number only` | Только номер страницы |

Эти маркеры используются для автоматического отчёта о качестве корпуса.
