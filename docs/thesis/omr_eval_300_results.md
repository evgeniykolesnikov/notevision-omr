# Результаты OMR evaluation на выборке 300 страниц

## 1. Дизайн эксперимента

Расширенная выборка
`data/labels/omr_eval_sample_300_thesis.csv` содержит 300 страниц из 39
документов. Она сформирована воспроизводимо с seed `42` и приоритетно включает
предыдущие OMR failures, расхождения page classifiers, страницы `mixed` и
кандидатов с низкой уверенностью моделей.

Эксперимент состоит из трёх последовательных этапов:

1. основной запуск Audiveris на страницах, извлечённых при 300 DPI;
2. fallback при 400 DPI только для страниц без MXL после основного запуска;
3. preprocessing fallback только для страниц, не восстановленных при 400 DPI.

Результаты этапов учитываются раздельно. Fallback recovery не изменяет primary
success rate, а используется только для расчёта итоговой комбинированной
доступности артефактов.

## 2. Основной OMR при 300 DPI

| Показатель | Значение |
|---|---:|
| Страниц в выборке | 300 |
| Документов | 39 |
| Страниц с MXL | 240 |
| Страниц с MIDI | 239 |
| MXL success rate | 80.00% |
| MIDI success rate | 79.67% |
| Страниц без MXL | 60 |
| MXL создан, MIDI отсутствует | 1 |

Primary OMR success равен `240/300` по MXL. MIDI сформирован для 239 страниц:
одна страница прошла Audiveris, но не прошла последующую MIDI-конвертацию.

## 3. Fallback при 400 DPI

На 400 DPI повторно обработаны только 60 страниц без MXL после primary OMR.

| Показатель | Значение |
|---|---:|
| Attempted | 60 |
| Recovered MXL | 16 |
| Recovered MIDI | 16 |
| Still failed | 44 |
| Recovery rate | 26.67% |
| Runtime | 592.10 секунд |

Увеличение разрешения восстановило 16 страниц. Этот результат показывает, что
часть failures связана с масштабом нотного стана и качеством входного
изображения, но 400 DPI не является универсальным решением.

## 4. Preprocessing fallback

Для оставшихся 44 страниц проверены четыре варианта:

- `crop_page`;
- `crop_deskew`;
- `crop_deskew_clahe`;
- `crop_deskew_adaptive_threshold`.

| Показатель | Значение |
|---|---:|
| Attempted pages | 44 |
| Recovered pages | 1 |
| Still failed | 43 |
| Recovery rate | 2.27% |
| Лучшая восстановленная страница | `rsl01004475471/page_019` |
| Лучший вариант | `crop_page` |

Preprocessing восстановил только одну дополнительную страницу. На текущей
выборке простое кадрирование оказалось полезнее более агрессивных вариантов,
однако одного случая недостаточно для общего вывода о лучшем preprocessing.

## 5. Итоговая комбинированная техническая успешность

| Артефакт | Primary | 400 DPI recovery | Preprocessing recovery | Итог |
|---|---:|---:|---:|---:|
| MXL | 240 | 16 | 1 | **257 / 300 (85.67%)** |
| MIDI | 239 | 16 | 1 | **256 / 300 (85.33%)** |

После всех fallback-этапов MXL отсутствует для 43 страниц:
`43/300 = 14.33%`. Кроме того, остаётся одна страница с MXL, но без MIDI.
Поэтому итоговая доступность MIDI на одну страницу ниже доступности MXL.

Важно различать четыре показателя:

- primary MXL success: **80.00%**;
- recovery среди primary failures при 400 DPI: **26.67%**;
- recovery среди оставшихся failures после preprocessing: **2.27%**;
- final combined MXL technical success: **85.67%**.

## 6. Интерпретация

По сравнению с экспериментом на 150 страницах primary success снизился с 94%
до 80%. Это ожидаемо для приоритетной диагностической выборки, обогащённой
известными failures, model disagreements, mixed и low-confidence страницами.
Результаты двух выборок нельзя напрямую трактовать как одинаково построенные
оценки генеральной совокупности.

Fallback 400 DPI дал основной прирост: 16 восстановленных страниц против одной
после preprocessing. Следующий анализ должен сосредоточиться на 43 оставшихся
страницах, типах верстки, качестве сканов и логах Audiveris.

## 7. Ограничение метрики

Все приведённые показатели характеризуют только наличие технических
артефактов MXL/MIDI. Созданный и успешно разобранный файл может содержать
ошибки высоты нот, длительностей, голосов, тактов и повторов. Musical
correctness должна оцениваться отдельно по экспертной разметке и сравнению со
сканом.
